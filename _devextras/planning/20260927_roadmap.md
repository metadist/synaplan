| Integrations page, editors, office | Large | Unchanged Wave 6. They do not gate row 1. |

## 3. In flight — not a new sprint

[#2207](https://github.com/metadist/synaplan/issues/2207) (`/pic` via an
OpenAI-compatible endpoint) is a bug, fixed in
[#2208](https://github.com/metadist/synaplan/pull/2208). Local image
model to point that endpoint at: **LocalAI + `flux.1-schnell`**.
Ollama’s `/v1` chat API does not serve `POST /v1/images/generations`.

Local **speech** model is a different stack and already ships here:
**whisper.cpp**, `WHISPER_DEFAULT_MODEL=base` (the dev compose uses
`tiny` for speed). Do not add LocalAI or a second STT engine in E1.

---

## 4. Down the road on purpose

- OpenClaw-style tools, computer use, or a second chat stack inside Telegram.
- `/images/edits` (pic2pic) and shipping LocalAI inside `docker-compose.yml`.
- Element Call live captions (OD-C) and a full openDesk Helm fork.
- Replacing the 1 200-line dev compose with the published image.
- Making container ports configurable. Only the published host port moves.
