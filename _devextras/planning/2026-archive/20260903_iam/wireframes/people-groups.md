# Wireframe — People → Groups

```text
┌─────────────────────────────────────────────────────────────┐
│ People                                         [Create group]│
│ [ Users ]  Groups                                           │
├──────────────────────────────┬──────────────────────────────┤
│ Name     Kind          #     │ Sales                        │
│ Sales    Manual        3     │ Members                      │
│ Support  From your     8     │ [ email… ] [Member ▾] [Add]  │
│          login               │ ada@…  Manager        Remove │
│                              │ bob@…  Member         Remove │
│                              │                              │
│                              │ Shared with this group       │
│                              │ Nothing is shared yet. (S2)  │
└──────────────────────────────┴──────────────────────────────┘
```

Directory groups show "From your login" and have no rename/delete/add.
Manual groups can be created, renamed, and deleted.
