Lean by design — switch on only what you need

The core is small: the app, its database and Redis. Everything below is an optional building block. Each one adds a capability and costs RAM — turn it on when you need it, off when you don't. This list shows what this installation is running right now.

Opt-in blocks use Compose profiles (docker compose --profile office up -d). Blocks that are on by default can be stopped with docker compose stop <name>; Synaplan keeps working and simply hides the matching feature. Details: README → Lean by design.

Connect an AI provider (2 min)

Synaplan talks to the AI of your choice. After you log in, a setup screen guides you: paste one API key (free keys: console.groq.com) — or use a local Ollama with a capable model, no key needed. Either way chat works instantly — no restart, no config files. Keys are validated live and stored encrypted in your own database.

Good to know

  • A small local AI model (~1 GB) downloads in the background for document search — chat does not wait for it.
  • Until a provider key is set, chat replies come from a built-in demo responder so you can try the interface.
  • Dev tools: email viewer · database browser · API docs
